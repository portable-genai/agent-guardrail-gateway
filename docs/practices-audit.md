Applicability: Hrz1 is a **horizontal control-plane service** (the runtime guardrail / redaction
policy proxy), **not** a document vertical. It ships **no `ui/`** (so `[ui]` checks are N-A) and
**does ship** Terraform (`infra/terraform/`, so `[infra]` applies). It performs **no grounded LLM
reasoning of its own** (Model Armor classifies, DLP de-identifies; there is no dossier/claim
generation), so several `[agentic]` checks (B1-B3, C3) are **N-A by design** and are marked as such
with a reason, not failed. It is a **stateless** proxy (no datastore, no session), which makes the
object-store checks (C2, C9) N-A. **Load-bearing** checks (a FAIL breaks a shared catalog guarantee)
are A1-A6, C1-C5, D1-D3 and E1.

grounded-LLM checks (B1-B3, C3), stateful object/audit checks (C2, C9), and the `[ui]` checks
